俺の実況 V12 Lite

特徴:
- 効果音なし
- 字幕なし
- 10枚フレーム解析
- プレー細分化
- 実況スタイル選択
- 盛り上がり度選択
- 実況品質スコア表示
- 実況だけ再生成
- AI音声生成
- MP4合成

使い方:
1. ZIPを解凍
2. cd ~/Downloads/oreno_jikkyo_v12_lite
3. npm install
4. cp .env.example .env
5. open -a TextEdit .env
6. APIキー保存
7. npm start
8. http://localhost:3000
